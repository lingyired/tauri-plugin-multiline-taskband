## Default Permission

Allows all multiline-taskband commands.

#### This default permission set includes the following:

- `allow-create`
- `allow-remove`
- `allow-set-text`
- `allow-set-font-sizes`
- `allow-set-layout`
- `allow-set-colors`
- `allow-set-bold`
- `allow-set-alignment`
- `allow-set-visible`
- `allow-rect`
- `allow-is-visible`
