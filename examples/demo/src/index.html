Multiline Taskband Plugin

multiline-taskband-demo · com.tauri.multiline-taskband-demo

5 taskbar instances (mb-1 … mb-5). Each instance is a two-line overlay on the taskbar; click one on the taskbar (or its Settings button below) to open its settings popup (text, font sizes, padding, colors, bold, alignment, side). All settings — text, appearance, side, shown/hidden, the global margin and any instances you create — are saved automatically and restored on the next launch.

Windows 10 / 11: left instances hug the taskbar's left edge, right instances sit next to the notification area (tray); same-side instances are laid out side by side in creation order.

Global settings

Options that apply to every taskbar instance (persisted).

Taskbar instances

    Click an item on the taskbar, or its Settings button, to open its settings popup.

    Create instance

    Create a new taskbar instance at runtime (unique id; empty text lines show the instance id). Created instances are persisted and restored on the next launch — remove them with the ✕ button on their row.
